# GUI Agent

面向电商发版回归的 GUI 自动化测试 Agent。项目围绕业务断言、可追溯轨迹和多模态模型训练建设，首期业务目标是 Android 上的商城 H5 回归测试。

当前状态见 [开发进度](docs/STATUS.md)。仓库处于初始开发阶段，设备执行和模型训练结果尚未验收。
