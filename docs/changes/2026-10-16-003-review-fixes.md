## 改动

1. 业务证据必须含合法的 expected/observed 原始值和布尔前置条件；undefined、null、对象、数组不能被相等比较误判通过。
2. 评测计划为每次尝试绑定唯一 run_id 与 case_id；复用同一运行结果或关联到其他业务用例会报错。
3. 非法动作输出使用明确的 ActionValidationError；模型连接、鉴权与服务故障归为 INFRA_ERROR，保留完整尝试。
4. 使用单调时钟在异步边界和动作派发前检查截止时间；定时器仍用于中止悬挂请求，同步任务拖延事件循环也不能触发超时后的动作。
